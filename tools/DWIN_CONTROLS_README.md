# DWIN Touch Zone Mapping — KobraMax-HC32

Generated by `tools/generate_dwin_controls.py` → `DWIN_SET/13TouchFile.bin`

## Binary Format

Each record is **32 bytes**, file ends with `FF FF` terminator.

```
Offset  Size  Content
0       2     Page number (big-endian uint16)
2       2     x0 — left edge (big-endian uint16)
4       2     y0 — top edge  (big-endian uint16)
6       2     x1 — right edge (big-endian uint16)
8       2     y1 — bottom edge (big-endian uint16)
10      7     FF 00 00 23 FE 05 FE  (fixed)
17      2     10 00  (KEY_ADDRESS = 0x1000, big-endian)
19      2     00 00  (padding)
21      1     Key code — written to KEY_ADDRESS on touch
22      10    00 × 10 (padding)
```

Firmware polls `KEY_ADDRESS` (0x1000) each loop, dispatches to `page*_handle()`, then resets it to 0.
