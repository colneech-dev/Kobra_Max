# Vendor reference documents

The display and processor documents this project was written from are published by their vendors; get them from there:

* DWIN T5L / DGUS II development guide: <https://www.dwin-global.com/> (Downloads).
* HC32F460 datasheet and user manual: <https://www.xhsc.com.cn/> (XHSC, formerly HDSC).

Note: the display notes in [../DISPLAY_NOTES.md](../DISPLAY_NOTES.md) are written in this project's own words from the guide and from
observation on a real display.
